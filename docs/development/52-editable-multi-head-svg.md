# 第五十二次迭代：可编辑的多头矩阵 SVG

用户要求将存在下标错误的生成图片重做为可编辑矢量图。本轮以原图构图为参照，使用原生 SVG 重建白底、八层矩阵叠放、最前层网格、汉字与 K 编号之间的分隔线和常规字重文字。

## 可编辑文件

- public/images/multi-head-matrices.svg：可直接编辑的独立矢量文件。所有文字保留为 text/tspan，线条、外框和文字分别组织成分组，没有嵌入位图或将文字转换为轮廓。
- scripts/generate-multi-head-matrix.mjs：生成源文件，可调整词元、坐标、字号和样式，再使用 Node 执行重新生成 SVG。直接编辑 SVG 后，请勿重新运行生成器覆盖手工修改；希望长期保留的修改也可以写入生成器。

## 正确性

列表示 Q₁ 至 Q₈，行表示 K₁ 至 K₈。64 个格子逐行生成 Kᵢ · Qⱼ，并以独立编号标识每个文字对象。保留图下注释对行列方向及得分/权重区别的说明。

网页改用 SVG，保留原来的显示宽度和宽高比。旧 PNG 不再用于网页，避免继续展示错误下标。

## 验证

浏览器读取实际 SVG 并核验八个 Query 标题、八个 Key 标题和全部 64 个公式，而非只检查图片加载。确认八张外框、无嵌入位图、桌面与手机无横向溢出。执行类型检查、36 项核心测试及生产构建；发布后核对线上文件与本地 SVG 完全一致。
