# 第二次迭代：交互实验界面

日期：2026-10-07（Asia/Shanghai）。基于第一阶段提交 `887fdb4`，完成交互网页，不扩展完整 Transformer。

## 需求与授权

用户询问下一阶段后，约定四项功能：向量数值/拖拽编辑；点积、缩放、Softmax、加权求和的分步展示；权重和输出可视化；基线保存、比较与重置。

本次用户授权原文：

> 帮我完成

核心验收场景：观察词元 A 的 Query，只把词元 B 的 V 从 `(0, 2)` 改为 `(0, 4)`，权重不变，输出 y 分量翻倍；重置恢复默认实验。

## 架构与实现

- 使用 React + TypeScript + Vite；安装时保存精确依赖版本，并更新锁文件。
- 复用第一阶段 `computeAttention`，不在图表中重复实现数学计算。
- 实验 reducer 管理输入、观察对象、编辑词元、图表类型、步骤和独立的基线快照。
- 观察对象与编辑对象分离，防止编辑 B 时自动切换观察的 Query。
- 数值输入与 SVG 拖拽更新同一份状态；聚焦输入框时切换对应图表类型；非法输入不改变计算结果。
- 使用 SVG 屏幕坐标变换处理拖拽和指针捕获；支持触摸和方向键操作。
- 基线深拷贝，与后续修改分离；刷新重新开始默认实验。
- 输出图同时容纳当前向量和基线，并显示坐标范围，避免过小的输出箭头难以辨认。
- 四步计算支持直接选择、前后导航和自动播放；权重始终由完整计算链生成。
- 网页产物放到 `site-dist/`，计算核心仍输出到 `dist/`；后台服务、数据库及外部 AI API 均不需要。

## 验证与修正过程

- 数学计算与实验状态的 19 项测试通过，核心和前端类型检查及构建通过。

- 在视觉检查中，补充输入框聚焦与坐标图类型的联动；修改 V 时立即展示 V，而不是保留 K 图。
