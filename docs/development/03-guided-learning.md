## 实现与约束

- 三个实验分别改变 B 的 K、B 的 V、A 的 K，对应关注对象、传递内容和归一化竞争。每次从已知初始参数开始，固定观察 A，仅开放指定词元的一类向量。
- `lessons.ts` 定义题目与目标，目标判断重新调用 `computeAttention`，验证其余向量保持初始值，不使用可被学习者修改的比较基线。
- `session.ts` 管理预测、操作、解释和完成四种状态。预测必须先提交；目标达成后冻结参数；理解题通过才记录完成；首次预测和理解题错误不被重试覆盖。
- `state.ts` 在 reducer 中约束可编辑向量与观察对象，输入框和 SVG 拖动/键盘同时遵守规则。切回自由探索恢复离开前的输入和基线。
- 四道自测使用独立数值，覆盖 Q/K 匹配、V 加权、零 Query 和 Softmax 共同平移；提交后逐题解释，分别展示首次与最近成绩。
- `progress.ts` 校验本地保存的版本、题号、数值和记录结构，限制保留数量并保留首次记录。完成实验保存独立输入、权重和输出快照；未完成会话不持久化。
- 保存限于当前浏览器的 `localStorage`。存储损坏时恢复空进度，存储不可用时提示用户并允许继续学习、导出匿名 JSON；没有后端、账号或额外依赖。
- 导出记录供试用复盘，包含首次判断和回答序列，不宣称重复练习分数能证明教学效果。
