# 第二十五次迭代 模块用途与操作说明归位

日期：2026-11-03（Asia/Shanghai）。使用说明首页改为八个模块的功能与用途卡片，按用户选定的介绍文案展示 Attention 引言、小栗子、自由探索、实验总结、引导实验、理解自测、多头注意力和三种 Attention。

将原来的四步操作放在自由探索，将热力图阅读说明放在热力图旁，将引导流程与进度保存说明放在引导实验，将换题、题目与成绩保存和导出说明放在理解自测。四处详细说明使用可展开的说明块；简化教学模型的范围合并到自由探索已有的实验介绍。首页仍为使用说明，页面切换保留实验与自测状态。

手机验收发现新增说明使引导结果区超出原来的滚动定位范围，将解释与完成阶段的滚动目标改为实际结果和理解题区域，避免用户需要额外寻找结果。已有浏览器验收检查这一行为。

类型检查、35 项核心测试、生产构建和 34 项浏览器验收通过。另在 1280、390、320 像素检查模块介绍、四处说明的展开与归属、参数保留、说明展开时的引导结果定位以及无横向溢出和运行时错误，并检查电脑和手机截图。
