# 第五十三次迭代：实时匹配得分与错题学习入口

## 结果区

每个词元显示“匹配得分 → 权重”，上方说明得分经过缩放和 Softmax 才成为权重。得分直接读取当前观察 Query 对应的原始点积结果，随 Q/K 和观察对象实时更新；修改 V 不改变得分或权重。桌面尽量同行，窄屏允许换行，保留原有柱状图、基线与输出对比。

## 错题入口

只在提交后回答错误的题目解析下显示学习按钮。匹配题进入“改变关注对象”，聚合、修改 V 和输出相关题进入“改变传递内容”，归一化及权重变化题进入“观察权重联动”。点积与余弦相似度题进入匹配任务。遮罩题进入“三种 Attention”的解释页，避免将没有遮罩操作的引导任务冒充为遮罩验证。

题目对应关系在展示层解析，不改题库题目、历史快照、评分与导出格式。同一个任务已有进度时恢复其输入、阶段和提示；其他目标按现有任务切换规则打开。自测首次打开后保留组件状态，跳转出去再回来不重新抽题、不重复记分，成绩和所选答案继续显示。点击“换一组题”仍明确开始新一轮。

## 验证

类型检查、36 项核心测试和生产构建通过。44 项浏览器检查覆盖得分随 Query/K 更新、V 修改保持得分、三个任务的定向跳转、已有任务恢复、自由探索参数恢复、自测题目与成绩保留、只对错题显示入口、遮罩说明跳转和窄屏无横向溢出。另检查实际桌面与手机显示效果，部署后核对线上行为。
