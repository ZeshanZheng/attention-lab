# 第十一次迭代 书和它的指代例子

日期：2026-10-08（Asia/Shanghai）。本次只增加演讲稿中“书”和“它”的指代例子，不扩展 PPT 中的多头、遮罩、完整架构或加性注意力等内容。用户要求按钮名为“小栗子🌰”，放在自由探索与实验总结之间，并尽量使用这一页的演讲稿。

## 讲解内容

新增独立阅读页面，按认识 Q 和 K、寻找相关位置、读取 V 的内容、融入上下文四步讲解。保留原稿的句子、“我、书、它”的身份和查询比喻、Embedding 与学习到的参数矩阵、Q/K 点积匹配、“书”的不同含义、V 的来源、向量偏移比喻，以及用数学向量完成信息聚合的说明。去掉演讲现场的“点下一页”，将原本的大段口语整理为短段。

句子随步骤突出“书”和“它”，对应文字说明匹配与信息传递的联系。第一步附自然语言 Q/K 比喻卡片与 X 到 Q/K/V 的投影说明。完整讲稿折叠区使用同一份讲解内容，展开后按原来的讲解顺序连续阅读，没有另删成仅含摘要的版本。

科学表述作以下调整：词性问答只是比喻，Q/K/V 本身是向量；“我”较不匹配是本例的直觉说明，不推断权重必为零；V 不能直接解释为字典词义的概率分布；输入表示由当前层决定；向量维度由模型配置决定；“偏移”说明表示更新，不宣称存在固定词义方向或单次 Attention 已解决指代。例子明确标注没有运行真实语言模型或计算实际句子权重。依据为 [Transformer 原论文 §3.2](https://arxiv.org/html/1706.03762v7)。

## 导航和阅读

导航顺序为 Attention 引言、自由探索、小栗子🌰、实验总结、引导实验、理解自测。默认仍为自由探索。沿用现有阅读导航，打开例子会暂停自动演示；返回实验和自测时保留页面中的向量、基线、计算步骤、引导状态、提示及未提交答案。小栗子的步骤与讲稿展开状态在当前页面内保留。

步骤按钮可直接选择，上一步与下一步在首末步骤禁用，支持键盘操作。桌面正文为 17px、手机正文为 16px；手机步骤入口分为两列，比喻卡片改为单列。底部“去自由探索”按钮连接到已有数字实验，不将自然语言示例伪装为真实模型输出。
