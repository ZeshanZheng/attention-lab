# 第九次迭代 Attention 背景导读

日期：2026-10-08（Asia/Shanghai）。用户希望在自由探索、引导实验和理解自测之前，介绍 Attention 的背景、它在 Transformer 中的位置和作用，以及学习它的价值。

## 页面内容

新增导读位于页面标题下方、三个学习模式按钮之前。默认展示一段通俗介绍和三块说明，分别回答“从哪里来”“在 Transformer 中做什么”“理解它有什么帮助”，再给出自由探索、引导实验、理解自测的学习顺序。

补充内容使用原生 details/summary 默认折叠，包含自注意力、跨注意力、多头和本实验范围，并用简化信息流突出 Attention 在编码器层中的位置。示意图明确省略残差连接与归一化等步骤，避免被误读为完整架构。桌面使用横向排列，手机改为纵向排列；展开状态在模式切换时保留，支持键盘操作。

引言中的历史与架构说明按[早期机器翻译注意力研究](https://arxiv.org/abs/1409.0473)和[Transformer 原论文](https://arxiv.org/html/1706.03762v7)核对，页面也提供可选阅读链接。人为设定的二维向量、单个注意力头和聚合输出仍明确标注为教学范围。

## 验证

严格类型检查、35 项数学与学习状态测试、构建和默认演示通过。全部 24 项浏览器验收通过，包括实验定位、模式切换、步骤播放、热力图、自测与学习记录兼容。

另外检查 1920、1280、900、390 像素宽度：导读在学习按钮之前，展开和折叠均无横向溢出；Enter 可切换补充说明，切换学习模式不丢失展开状态或改变实验输入，没有页面运行时错误。
