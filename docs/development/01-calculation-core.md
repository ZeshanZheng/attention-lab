## 实现约束与过程

- 使用标准缩放点积 Attention；将点积称为匹配得分，不将其等同于余弦相似度。
- 使用人工设定的教学向量；输出是聚合后的向量，不是下一个词的预测。
- 使用 TypeScript 纯函数，计算和界面分离，不进行网络请求，不更改调用者的输入。
- 起始目录为空，系统 PATH 中没有 Node.js。通过项目本地脚本下载固定版本 Node.js，并核对官方 SHA256 校验值。
- 初始化提交仅记录工程脚手架和本次需求；计算功能另行提交，保留真实开发顺序。
