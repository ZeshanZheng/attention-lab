## 设计和交互

在实验面板下方增加独立的 3 × 3 热力图，行表示 Query，列表示 Key，显示全部九个 Attention 权重的百分比。高亮行对应当前观察对象，矩阵与柱状图、计算步骤共用 `computeAttention` 的结果，没有在图表中重新实现数学。

使用固定的 0–1 紫色色阶，避免每次编辑后按最大值重新缩放导致同一种颜色含义改变。根据背景亮度选择黑色或白色数字，同时保留数值、行标记与详细解释，不仅依赖颜色传达信息。

悬停、Tab 聚焦或点选单元格可查看该 Query/Key 组合的实际点积、缩放得分、当前权重、基线权重与差值。自由探索中点击或按 Enter 会同步切换观察 Query，编辑词元保持原选择；外部 Query 按钮切换后，详情跟随新观察行。

引导实验保持观察 A，热力图仍允许检查其他行的数值，不解除向量编辑或 Query 的限制。只修改 V 时所有权重和颜色保持不变。说明每行独立归一化，以及百分比四舍五入可能导致显示合计略偏离 100%。

用原生 HTML 表格标记行/列，单元格使用按钮；支持键盘、鼠标和手机点选。桌面显示介绍、矩阵和详情三列，小屏改为纵向排列。没有新增依赖、后端或环境配置。

## 验证与修正

严格类型检查、34 项核心与学习状态测试、模块编译、网页构建和默认演示通过。

21 项浏览器验收通过，其中新增 5 项验证：

1. 全部九格数值来自实际计算，各行分别归一化，详情中的权重/基线/点积正确。
2. 点击和键盘 Enter 同步观察 Query、柱状图与计算对象，聚焦查看其他行时不自动切换；编辑词元保持不变。
3. 修改 K 后矩阵相应更新，本例 Q_B 的 x 为 0，因此对应行保持不变；修改 Q_A 仅改变 A 行。保存基线、恢复和重置保持一致。
4. 只改 B 的 V y 到 4，输出为 `(0.872, 1.136)`，全部九格权重和颜色保持原值。
5. 390 × 844 手机布局无横向溢出，可点选查看详情；引导实验的 A 行和编辑门禁不被热力图绕过。

初次类型检查提示启用 `exactOptionalPropertyTypes` 时不能向可选回调直接传入 `undefined`，调整为显式的回调或 `undefined` 联合类型后通过。初次浏览器检查有一项颜色断言在 150ms 过渡开始前读取旧颜色；修改测试以读取目标样式，并等待实际背景色达到目标值后验证，保留界面过渡动画。

桌面和手机热力图截图已检查，保存在 `docs/images/heatmap.png` 与 `docs/images/heatmap-mobile.png`。现有学习记录格式与题库不变；完整 AI 对话仍需另行保留，本文为实际开发摘要。
