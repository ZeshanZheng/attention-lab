# 第三十五次迭代 独立欢迎页与进入实验室流程

日期：2026-11-04（Asia/Shanghai）。

用户希望打开网页时只先看到欢迎语和学习目标，并确认下方放“进入实验室”按钮，每次打开或刷新均显示欢迎页。采用独立全屏布局，淡紫白背景、细圆弧装饰和居中两级标题，保留原来的两句话；按钮进入后才挂载实验室。欢迎页不显示实验室页眉、导航、学习记录和模块正文，也不依赖存储判断是否显示。按钮支持 Tab 和 Enter，进入后聚焦使用说明导航。

原使用说明中的欢迎语和学习目标移到新页面，使用说明直接从“认识 Attention”开始，保留三项概览、建议路线和八个模块入口。实验室原有计算、阶段状态与已保存学习记录保持原有规则。共享浏览器打开辅助函数显式经过欢迎入口，刷新验收也点击入口后再检查学习记录，未增加绕过欢迎页的产品接口。

验证：严格类型检查、35 项核心测试与生产构建通过。原有 35 项浏览器验收通过；新增三项覆盖独立欢迎页、键盘进入、刷新返回和 320/390 像素小屏入口。另以 1440×900、1280×720、390×844、320×568、844×390 检查两句话与单一入口、使用说明与八个模块保留、刷新返回、无横向溢出和运行时错误，并查看电脑与手机截图。
