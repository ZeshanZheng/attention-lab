# 第四十四次迭代：进入引导任务时显示模块栏

日期：2026-11-07（Asia/Shanghai）。

原先进入引导任务时会按当前任务阶段滚动到任务卡或向量输入区，导致上方模块栏离开视口。本次区分“进入引导任务”和“在任务中推进阶段”：首次切换、从自由探索切回、从阅读页或自测返回时，定位到模块栏；记录预测后再定位并聚焦可编辑输入框，目标达成后仍定位到理解题。选择新任务或重新开始预测时也显示模块栏。

任务参数、提示、理解题选项和完成记录的恢复规则保留。更新已有浏览器验收，在桌面和 320 像素手机宽度检查预测、修改、解释、完成阶段切回时模块栏完整显示且位于顶部品牌栏下方，并继续检查记录预测后的输入聚焦和固定目标栏。

本地严格类型检查、36 项核心测试、生产构建和 9 项相关浏览器验收通过；另在 1920、1280、390、320 像素检查进入时模块栏可见、任务恢复、独立基线和无整页横向溢出，并查看桌面截图。
