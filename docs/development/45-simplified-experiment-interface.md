# 第四十五次迭代：精简动手实验界面

日期：2026-11-07（Asia/Shanghai）。

按用户确认的方案，将实验主界面从编辑、计算、结果三列改为编辑与结果两列。自由探索选择词元及 Q/K/V 后，一次展示一个向量的 x、y 输入；引导任务只展示目标向量，其他向量通过“查看其他向量”只读查看。输入向量坐标图在电脑默认展开，手机默认收起，均可随时展开或收起。结果区直接显示三个权重、输出数值和修改前后的差值，输出坐标图按需展开。

计算过程移到操作区下方，默认收起；展开后保留四步手动切换，首先呈现简短说明、公式和当前数值例子。“详细解释”收纳原有输入、结果、用途、符号、当前 Query 及逐项计算。热力图移入“查看所有词元的注意力”，保存和恢复基线移入“对比设置”；模型范围与操作说明也可按需展开。没有删去原有计算与解释。

引导任务固定观察 A，原有编辑限制、目标判断、首次预测、理解题重试和完成记录保留。目标是修改 K 时突出权重区域，修改 V 时突出输出区域；例如第二个任务按真实结果提示“注意力权重没有变化，输出的 y 分量变大了”。两种方式仍共用同一套输入、计算和结果，切换时保留各自参数、基线、步骤和任务状态；进入任务时仍显示模块栏，记录预测后定位输入。

调整原有浏览器验收以按照新的入口操作，新增两项验收：默认信息层级与两列排列、展开计算后的实时数值及基线一致性；手机只展示目标向量、只读其他向量、结果突出和完整完成任务。类型检查、36 项核心测试、生产构建及 42 项浏览器验收通过；另在 1920、1280、768、390、320 像素检查布局、展开入口、输入数量、真实数值和无整页横向溢出，并查看桌面与手机截图。
