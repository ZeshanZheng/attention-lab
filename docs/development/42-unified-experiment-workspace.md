# 第四十二次迭代：统一动手实验

日期：2026-11-07（Asia/Shanghai）。

原先自由探索与引导实验使用相同的计算面板，但作为两个顶部模块展示，入口和说明重复。本次将它们合并为“动手实验”，在模块内提供“自由探索”和“引导任务”两个按钮，共用向量编辑、四步计算、结果比较与权重热力图。顶部及使用说明入口同步调整，学习顺序为使用说明、Attention 引言、小栗子、动手实验、实验总结、理解自测、两个进阶阅读页面。

引导任务改为三个紧凑的选择按钮和阶段进度，移除原有左右分栏，避免任务说明区留下大片空白。预测阶段展示预测题，修改阶段保留提示与可展开的首次预测，目标和检查按钮放在固定目标栏；达成目标后冻结向量并展示理解题，完成阶段可展开本次观察记录。第三个任务完成后优先进入实验总结，也可直接进入自测。自由探索的模型范围介绍与操作说明放在操作区之后。

两种方式使用独立状态快照。自由探索保留参数、保存的基线、观察对象和计算步骤；引导任务保留预测、编辑进度、提示、理解题选择与编辑锁定。切到阅读页或自测再返回，恢复最近使用的实验方式。任务基线保持初始参数，不受自由探索保存基线影响。既有学习记录、首次错误、题目历史、导出格式和刷新规则保留。

验证包括严格类型检查、36 项核心测试和 40 项浏览器验收。新增测试实际执行预测、修改、解释和完成阶段中的方式切换，核对独立基线、冻结状态、提示与理解题选择，确认复用同一个操作面板，并在 320 像素手机宽度验证键盘切换、输入定位和无整页横向溢出。
