# Attention 实验室真人试用

目前没有真人试用数据。以下流程与空白表用于收集真实证据；自动测试截图中的答题结果只说明程序功能正常。

## 参与者与准备

邀请 5–8 位尚未系统学习 Attention 的同学，每人约 20 分钟。使用 P01、P02 等编号记录，不需要姓名或账号。提前说明记录仅用于改进教学体验与整理参赛材料；导出文件是否提供由参与者决定。

直接打开[线上实验室](https://zeshanzheng.github.io/attention-lab/)，或按 README 启动本地网页。每位参与者使用独立浏览器配置或无痕窗口，在同一窗口完成全程，结束前导出记录。已有学习记录的浏览器不用于新参与者的首次试用。

准备秒表、[空白记录表](user-testing-template.csv)，并告诉参与者：“请边操作边说出你的想法，遇到不懂的地方可以说明。”主持人先观察，避免提前讲解答案。

## 每人流程

1. **学习前访谈，约 2 分钟。** 记录是否听过 Q/K/V；请其用自己的话解释“关注谁”和“传递什么”是否相同。不打开自测，不展示答案，原话写入记录。
2. **自由探索，约 2 分钟。** 只要求找到向量编辑、权重和输出的位置，记录第一次操作的困难；不讲授三个实验的解法。
3. **三个引导实验，约 10 分钟。** 从“引导实验”开始，记录总用时、是否用了提示、停顿位置、是否理解锁定参数的原因。遇到无法继续的操作问题可以帮助，具体帮助必须记下；不要把受帮助的完成写成独立完成。
4. **首次理解自测，约 3 分钟。** 独立答完本轮 5 道题并提交，记录分数、分母、题号与错题。看过解释后可以换一组题重试，新题组与成绩单独记录；题目随机，不同参与者不一定遇到相同题组。
5. **学习后访谈，约 3 分钟。** 请其解释“为什么改 V 不会改变权重”“为什么一个词元权重上升会影响其他词元”，并指出最难理解或最有帮助的位置。记录原话，不只记录“懂了”。
6. **导出。** 使用“导出记录”下载 JSON。如参与者愿意提供，改名为 `P01-learning.json` 等与编号对应；填写 CSV，保留实际操作问题及帮助内容。

## 记录与解释

CSV 中 `independent_completion` 填“是/否”，`hints_used` 填实际使用的提示次数；没有观察到的项目留空，不填猜测。`duration_seconds` 是三个实验的实际耗时。完成实验的首次预测和理解题回答序列可从 JSON 核对；未完成实验、提示次数、操作障碍和主持人帮助需要现场记录，应用不会自动保存这些信息。

汇总首次自测分数、独立完成人数、常见错题与操作问题，展示具体反馈和后续修改。保留首答与重试差别，避免将看过反馈后的高分写为首次掌握。

随机题组覆盖相同的五类概念，但尚未校准难度。分析时保留实际题目，不把不同题组的分数直接解释为学习提升；旧版四题与新版五题也应分开记录。

此小样本试用用于发现可用性问题、获得理解情况的初步证据。学习前后访谈不是标准化前后测，不能据此声称“理解能力提高了某个百分比”或证明长期学习效果。如需定量比较，应另行设计难度相当的前后题和对照流程。

## 参赛材料可写什么

试用完成后，按真实情况写参与人数、背景、独立完成情况、首次答题结果、典型困难与对应改进。保留原始匿名记录和经过参与者同意的片段。试用前只写“已准备试用流程，尚未收集结果”。
